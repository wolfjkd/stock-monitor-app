# Stock Monitor App v4.0 - A股价格预警监控系统（桌面版）

> 开发计划书 | 2026-06-09

---

## 📋 项目概述

基于Web版（v3.0）核心代码，开发独立的Windows桌面应用，支持系统托盘后台运行，无需打开浏览器。

| 项目 | 版本 | 说明 |
|------|------|------|
| [stock-monitor](https://github.com/wolfjkd/stock-monitor) | CLI版 v2.0 | 命令行工具 |
| [stock-monitor-web](https://github.com/wolfjkd/stock-monitor-web) | Web版 v3.0 | 浏览器访问 |
| **stock-monitor-app** | 桌面版 v4.0 | 独立程序，系统托盘 |

---

## 🎯 核心目标

1. **系统托盘运行** - 后台运行，不占任务栏
2. **独立窗口** - 无需打开浏览器，像原生APP
3. **代码复用** - 最大程度复用Web版代码
4. **轻量打包** - 安装包 < 30MB

---

## 🏗️ 技术方案

### 方案对比

| 方案 | 体积 | 开发难度 | 代码复用 | 系统托盘 |
|------|------|----------|----------|----------|
| **Electron** | ~150MB | 中 | ✅ 100% | ✅ |
| **Tauri** | ~5MB | 高（需Rust） | ✅ 100% | ✅ |
| **pywebview + pystray** | ~20MB | 低 | ✅ 90% | ✅ |
| PyQt/PySide | ~30MB | 中 | ❌ 需重写 | ✅ |

### 推荐方案：pywebview + pystray

**理由**：
- ✅ Python技术栈，与Web版一致
- ✅ 前端HTML/JS可直接复用
- ✅ Flask后端可直接复用
- ✅ 系统托盘功能成熟
- ✅ 打包体积小（~20MB）
- ❌ 仅支持Windows（满足当前需求）

## 🔧 核心功能

### 1. 系统托盘模块

```python
# tray.py
import pystray
from PIL import Image

class SystemTray:
    def __init__(self):
        self.icon = pystray.Icon(
            "stock-monitor",
            self.create_icon(),
            "A股价格预警监控",
            menu=self.create_menu()
        )
    
    def create_menu(self):
        return pystray.Menu(
            pystray.MenuItem("显示主窗口", self.show_window),
            pystray.MenuItem("启动监控", self.start_monitor),
            pystray.MenuItem("停止监控", self.stop_monitor),
            pystray.Menu.SEPARATOR,
            pystray.MenuItem("退出", self.quit)
        )
```

### 2. 窗口管理模块

```python
# window.py
import webview

class AppWindow:
    def __init__(self):
        self.window = webview.create_window(
            "A股价格预警监控 v4.0",
            "http://localhost:5000",
            width=1200,
            height=800,
            resizable=True,
            min_size=(800, 600)
        )
```

### 3. Flask后端（复用）

```python
# server.py - 直接复用Web版app.py
from stock_monitor_web.app import app, monitor_state, VERSION

    app.run(host='127.0.0.1', port=5000, debug=False)
```

## 📊 打包方案

### PyInstaller配置

```python
# build.py
import PyInstaller.__main__

PyInstaller.__main__.run([
    'main.py',
    '--name=StockMonitor',
    '--onefile',
    '--windowed',
    '--icon=static/icon/app.ico',
    '--add-data=templates;templates',
    '--add-data=static;static',
    '--add-data=scripts;scripts',
    '--hidden-import=eltdx',
    '--hidden-import=flask',
])
```

### 输出

```
dist/
└── StockMonitor.exe    # ~20MB，独立运行
```
